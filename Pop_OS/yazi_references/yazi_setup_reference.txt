3. Make `y` launch Yazi and CD into the directory you exit from

Create:

mkdir -p ~/.config/fish/functions
nvim ~/.config/fish/functions/y.fish

Put:

function y
    set tmp (mktemp -t "yazi-cwd.XXXXXX")

    command yazi $argv --cwd-file="$tmp"

    if read -z cwd < "$tmp"; and test "$cwd" != "$PWD"; and test -d "$cwd"
        builtin cd -- "$cwd"
    end

    rm -f -- "$tmp"
end

Now:

y

opens Yazi.

If you navigate somewhere in Yazi and quit, your Fish shell remains in that directory.

Important fix you encountered

You previously had:

alias y='yazi'

That shadowed the Fish function.

Remove that alias from your Fish config if present.

Your wrapper function should be the thing handling `y`.

15. Yazi tabs

You found that Yazi supports real tabs.

Your merged keymap included:

tt       create tab in current directory
tr       rename current tab

1        tab 1
2        tab 2
3        tab 3
...
9        tab 9

[        previous tab
]        next tab

{        move/swap tab left
}        move/swap tab right

Internally these correspond to commands such as:

tab_create --current
tab_rename --interactive
tab_switch 0
tab_switch 1

etc.

That gives you a pretty nice terminal file-manager workflow without needing a separate Yazi process for every location.
