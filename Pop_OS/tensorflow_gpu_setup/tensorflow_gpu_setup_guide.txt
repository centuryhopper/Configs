===============================================================================
TensorFlow GPU Setup & Fix Guide (Fish Shell & uv)
===============================================================================

PROBLEM OVERVIEW:
-----------------
When running `tensorflow.config.list_physical_devices('GPU')`, TensorFlow returns an
empty list `[]` with the following warning:

    "Cannot dlopen some GPU libraries. Please make sure the missing libraries
     mentioned above are installed properly..."

CAUSE:
------
PyPI-installed NVIDIA packages (`nvidia-cuda-runtime-cu12`, `nvidia-cudnn-cu12`, etc.)
place dynamic libraries (`.so` files) into the Python virtual environment's `site-packages`
directory. Linux's dynamic linker does not search `site-packages` by default, so TensorFlow
cannot find the CUDA runtime, cuDNN, cuBLAS, and other required shared libraries.

===============================================================================
STEP-BY-STEP RESOLUTION
===============================================================================

1. Install Full NVIDIA CUDA Dependencies via uv
-----------------------------------------------
Ensure all required CUDA libraries are installed in your virtual environment:

    uv pip install "tensorflow[and-cuda]"

Or install individual packages:

    uv pip install nvidia-cuda-runtime-cu12 nvidia-cudnn-cu12 nvidia-cublas-cu12 \
                   nvidia-cuda-nvrtc-cu12 nvidia-cufft-cu12 nvidia-curand-cu12 \
                   nvidia-cusolver-cu12 nvidia-cusparse-cu12 nvidia-nccl-cu12

2. Set LD_LIBRARY_PATH in Fish Shell (Temporary Test)
------------------------------------------------------
Export the library paths for the current shell session:

    set -gx LD_LIBRARY_PATH (uv run python -c 'import site; print(":".join([f"{p}/nvidia/{sub}/lib" for p in site.getsitepackages() for sub in ["cuda_runtime", "cudnn", "cublas", "cuda_nvrtc", "cufft", "curand", "cusolver", "cusparse", "nccl"]]))' 2>/dev/null) $LD_LIBRARY_PATH

3. Verify GPU Recognition
-------------------------
Run the GPU detection snippet:

    uv run python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"

Expected Output:
    [PhysicalDevice(name='/physical_device:GPU:0', device_type='GPU')]

===============================================================================
PERMANENT SETUP OPTIONS
===============================================================================

Option A: Global Fish Shell Configuration (Recommended)
--------------------------------------------------------
Add the path export to your Fish shell startup config (~/.config/fish/config.fish):

    echo 'set -gx LD_LIBRARY_PATH (python -c "import site; print(":".join([f"{p}/nvidia/{sub}/lib" for p in site.getsitepackages() for sub in ["cuda_runtime", "cudnn", "cublas", "cuda_nvrtc", "cufft", "curand", "cusolver", "cusparse", "nccl"]]))" 2>/dev/null) $LD_LIBRARY_PATH' >> ~/.config/fish/config.fish

Option B: Virtual Environment Activation Script
-----------------------------------------------
Append to your project's `.venv/bin/activate.fish`:

    echo 'set -gx LD_LIBRARY_PATH (python -c "import site; print(":".join([f"{p}/nvidia/{sub}/lib" for p in site.getsitepackages() for sub in ["cuda_runtime", "cudnn", "cublas", "cuda_nvrtc", "cufft", "curand", "cusolver", "cusparse", "nccl"]]))" 2>/dev/null) $LD_LIBRARY_PATH' >> .venv/bin/activate.fish

===============================================================================
TROUBLESHOOTING & DIAGNOSTICS
===============================================================================

If GPU detection fails in the future:

1. Check host driver health:
    nvidia-smi

2. Inspect missing dynamic libraries using LD_DEBUG:
    env LD_DEBUG=libs uv run python -c "import tensorflow as tf; tf.config.list_physical_devices('GPU')" 2>&1 | string match -i "*failed to map segment*"
